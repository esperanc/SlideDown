# Markdown Support

You can write **bold**, *italic*, and `inline code`.

> Blockquotes are also supported and styled beautifully.

Lists work as expected:
- Item 1
- Item 2
    - Subitem

---

# Syntax Highlighting

We support automatic syntax highlighting for code blocks.

```python
def hello_world():
    print("Welcome to SlideDown!")
    # Comments are readable in dark mode too!
    return True
```

```javascript
const demo = "Working!";
console.log(demo);
```
