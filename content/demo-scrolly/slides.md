# Split Screen Scrolly

Keep code on the left while revealing explanations on the right.

::: row
::: col
```python
# The Turtle moves!
make_turtle(400, 400)

forward(100)
left(90)

forward(100)
left(90)
```
:::

::: col reveal
- We initialize the turtle screen.
- Move forward by 100 pixels.
- Turn left 90 degrees.
- Move forward again...
- And turn left again.
