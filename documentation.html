SlideDown

Documentação Oficial do Sistema

O SlideDown é um sistema web leve e modular para criar apresentações no estilo scrollytelling. Ele permite escrever slides usando uma linguagem de texto baseada em Markdown, suportando layouts complexos, multimídia e interatividade, sem a necessidade de escrever HTML manualmente.

1. Visão Geral e Arquitetura

O sistema funciona como uma Single Page Application (SPA) estática.

  1. Engine Universal (index.html): Carrega os scripts principais e gerencia o estado da aplicação.
  2. Parser (parser.js): Lê arquivos .md e os converte em uma Árvore de Sintaxe Abstrata (AST) JSON.
  3. Renderer (renderer.js): Recebe a AST e gera o DOM HTML dinamicamente, aplicando classes CSS e scripts de comportamento.
  4. Navegação (navigation.js): Gerencia o scroll, atalhos de teclado e persistência de sessão.

2. Como Rodar

Devido às políticas de segurança dos navegadores (CORS), o SlideDown não pode carregar arquivos locais diretamente. É necessário um servidor HTTP local.

# Python 3
python -m http.server

# Node.js
npx http-server

Acesse http://localhost:8000 no seu navegador.

4. Referência da Linguagem

4.1. Definição de Slides

Use três traços --- para separar um slide do outro.

# Slide 1
Conteúdo...
---
# Slide 2
Conteúdo...

4.2. Blocos de Layout

Use ::: tipo para criar estruturas.

Tipo Descrição
row Cria uma linha horizontal. Filhos ficam lado a lado.
col Cria uma coluna vertical.
center Centraliza todo o conteúdo (capas, títulos).

4.3. Componentes Especiais

Use :: nome { params } para inserir objetos ricos.

Imagem (com Zoom)

:: image { "src": "foto.jpg", "alt": "Legenda" }

YouTube

:: youtube { "id": "dQw4w9WgXcQ" }

Iframe Genérico

:: iframe { "src": "https://url-do-embed.com" }

5. Funcionalidades do Player

  • Navegação: Scroll suave, teclas de seta ou menu lateral.
  • Auto-Save: O sistema lembra em qual slide você parou ao recarregar a página.
  • Zoom: Clique em qualquer imagem gerada com :: image para ampliar e arrastar.
